# 인천상륙작전 — 밀물을 잡아라

1950년 9월 15일 인천상륙작전을 소재로 한 브라우저 역사 체험 게임입니다.
인천 제물포 AI 교육센터 전시용으로 만들었습니다.

- 바로 하기: https://cks817s-alt.github.io/incheon-game/
- 자동 시연(데모) 보기: https://cks817s-alt.github.io/incheon-game/#demo
- 쇼츠형 6·25 전쟁 지도 브리핑 → 팔미도 등대(새벽) → 월미도 상륙(아침 밀물) → 레드 비치 방파제(저녁 밀물)의 3단계를 밀물 시간에 맞춰 돌파합니다.
- PERFECT·GREAT·GOOD 타이밍 판정, 콤보 배율, 콤보 10마다 '총공격'(점수 2배), 계급 진급(이등병 → 대장), 작전마다 별 3개, 숨겨진 비밀문서 3장.
- 단계 시작 컷인에는 실제 작전 사진이 나오고, 끝나면 실제 작전 기록과 이름 없는 영웅들을 기리는 엔딩 크레딧, 사진 복습 퀴즈, 오늘의 순위가 이어집니다.
- 모든 한반도 지도에 독도·울릉도를 표시했습니다.
- 파일 하나(`index.html`)로 동작하며 인터넷 없이도 실행됩니다. 아무도 없으면 자동 데모가 돌아가고, 입력이 없으면 처음 화면으로 돌아갑니다.
